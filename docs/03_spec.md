# 要件定義書

> 元になった顧客仮説: `docs/01_customer.md`（斉藤内科・院長）
> 🔮 が付いた行は、まだ確かめていない仮説にもとづく決めごとです。

## 1. このツールが解くこと

**結果が返ってきたのに、まだ電話していない人が、返ってきた順に、開いた瞬間に分かる。**（結果として、1日15分の「探す時間」と、かけ忘れが減る）

## 2. 使う人と、使う場面

- **使う人**: 🔮 斉藤内科の院長。受付スタッフも同じ画面を見る想定だが、**入力するのは1人**（共有・権限分けは今回作らない）
  （→ 確かめ方: 「検査結果の電話は、先生ご自身がかけていますか？ 受付の方ですか？」）
- **いつ開くか**: 🔮 検査会社から結果が届いたとき（届いた分をまとめて登録する）と、**電話をかける時間帯＝昼休み・診療後**
  （→ 確かめ方: 「結果が返ってきた日、どのタイミングで電話していますか？」）
- **開いて最初にしたいこと**: **まだ電話していない人が、何人、返ってきてから何日経っているか**を見る

## 3. 画面（テンプレートの3画面をそのまま使う）

画面は **一覧 / 新規登録 / 設定** の3つ。左メニューで切り替える。ルーティングは増やさない。

**「一覧」に、上から順にこれが表示される:**

1. **数字が3つ**（未連絡 / 2日以上経過 / 全件）── **未連絡**の数がいちばん大きく出る
2. **検索欄と絞り込み**（未連絡 ⇄ 連絡済み ⇄ 全部。**最初は「未連絡」が選ばれた状態**で開く）。検索はカルテ番号・姓・メモに効く
3. **連絡待ちの一覧**（**結果が返ってきた日が古い順＝待たせている順**。各行に カルテ番号と姓・検査の種類・返ってきた日と経過日数・メモ・状態を切り替えるボタン）

- **新規登録**: 4項目（患者／検査の種類／結果が返ってきた日／メモ）を入れて保存 → 一覧に「連絡待ち」で追加される
- **設定**: 画面の表示名の変更と、データの初期化（全消し）。あわせて**「このブラウザの中だけに保存されます／検査値・所見は入力しないでください」**の1行だけ置く

> ⛔ この画面に、キャッチコピー・課題の説明・「無料で始める」等のCTA・営業文は出さない。
> ⛔ この文書の「6. やらないこと」や `docs/01_customer.md` の 🔮 仮説・出口の話は、画面に出さない（社内メモ）。

## 4. データ項目

**1種類のデータ =「返ってきた検査結果 1件」**。項目は5つ。

| 項目 | 型 | 必須 | 例 |
|---|---|---|---|
| 患者（カルテ番号＋姓） | 文字 | ✔ | 1042 見本A |
| 検査の種類 | 選択肢（血液 / 尿 / 病理 / 画像 / その他） | ✔ | 血液 |
| 結果が返ってきた日 | 日付（YYYY-MM-DD） | ✔ | 2026-08-19 |
| メモ | 文字（自由入力・空でよい） | | 夕方以降につながりやすい／携帯へ |
| 連絡状況 | 連絡待ち / 不在・かけ直し / 連絡済み | ✔ | 連絡待ち（新規登録すると必ずこれで入る） |

- **氏名はフルネームにしない。** カルテ番号＋姓で運用できる形にする（`docs/01_customer.md` ③ の確定制約）
- **検査結果の数値・所見は持たない。** メモ欄にも書かない前提で、入力欄の下に注意を1行出す（同上）
- 🔮 **検査の種類をこの5つにした根拠**: 外部の検査会社に出すものとして自然な区分＋取りこぼし用に「その他」。
  → 確かめ方: 「外に出している検査は、だいたい何と何ですか？」
- 🔮 **「不在・かけ直し」を入れた根拠**: 1日10人に電話すれば必ず不在が出る。ここが無いと、**かけたのに繋がらなかった人**を「連絡済み」にするか「連絡待ち」に戻すかしか無くなり、どちらも事実と違う記録になるため。**状態を増やすのはここ1つだけ**にする。
  → 確かめ方: 「電話して出ない方って、1日に何人くらいいますか？ そのあとどうしていますか？」

## 5. 操作（3つまで）

| # | 操作 | 何が起きるか |
|---|---|---|
| 1 | **新規登録する** | 4項目を入力して保存 → 一覧の先頭ではなく**返ってきた日の正しい位置**に「連絡待ち」で入る。上部の「未連絡」が1増える |
| 2 | **状態を切り替える** | 行の「連絡済み」を押すと未連絡の一覧から消え、「未連絡」の数が1減る。「不在」を押すと**未連絡に残ったまま**印だけ付く。**押し間違いは、もう一度押せば戻せる** |
| 3 | **探す（検索・絞り込み）** | カルテ番号・姓・メモの文字で検索。未連絡／連絡済み／全部の切り替え。「先週の血液のあの人」を数秒で出す |

> 一覧の行からの **編集・削除** は、テンプレートに既にある補助操作としてそのまま残す（入力ミスの直し用）。新しく作り込むのは上の3つだけ。

## 6. やらないこと

（`CLAUDE.md` 3章＋今回の範囲外）

1. **検査会社・電子カルテとの自動連携をしない。** 結果が返ってきたら、院内の人が手で1件登録する
2. **患者さん側の画面と自動通知を作らない。** 結果の閲覧・SMS・自動架電・予約は無し
3. **検査結果の数値・所見を持たない。** 持つのは「連絡が必要か」と「電話したか」だけ。**カルテの代わりにはしない**
4. **連絡状況を4段階以上にしない。** 「連絡待ち／不在・かけ直し／連絡済み」の3つで止める。再診時の説明・紹介状は追わない
5. **ログイン・課金・メール送信・通知を作らない**（第3回で扱う）
6. **複数人での共有・サーバー保存をしない。** データはこの端末の中だけに置く（要配慮個人情報のため、これは今回いちばん動かせない線）
7. **新しいライブラリを追加しない。** テンプレートの構成（Next.js＋プレーンCSS）のまま

## 7. 完成条件

- [ ] **画面を開いた最初の状態で、「まだ電話していない人」だけが、結果が返ってきた日の古い順（＝待たせている順）に上から並んでいる**
- [ ] **新規登録から1件追加して、ブラウザを再読み込みしても、その1件が残っている**
- [ ] **一覧で「連絡済み」を押すと、その人が未連絡の一覧から消え、上部の「未連絡」の数字が1減る**

## 8. 保存方法

`localStorage` に1つのキーで保存する。キー名: **`followup-data`**（表示名は `followup-appname`）

- 読み書きは `useEffect` の中だけで行う（`CLAUDE.md` 5-2章のとおり）
- ※ 端末ごとの保存です。複数人での共有は第3回で扱います。
- ※ 患者情報を扱うため、**外部サーバーへは一切送りません**。この設計は変えません。

## 9. ダミーデータ

初回表示で寂しくないよう、サンプルを3件入れる。**実在の人名・連絡先は使わない**（`見本A` のように、ひと目でサンプルと分かる姓にする）。
日付は「今日から◯日前」で作り、いつ開いても経過日数が自然に見えるようにする。

| 患者 | 検査の種類 | 返ってきた日 | メモ | 連絡状況 |
|---|---|---|---|---|
| 1042 見本A | 血液 | 4日前 | 夕方以降につながりやすい | 連絡待ち |
| 1187 見本B | 尿 | 2日前 | （空） | 不在・かけ直し |
| 1203 見本C | 画像 | 1日前 | （空） | 連絡済み |

> この3件で、**「経過日数が長い順に上へ」「不在は未連絡に残る」「連絡済みは既定の一覧に出ない」**の3つが、開いた瞬間に確認できます。
