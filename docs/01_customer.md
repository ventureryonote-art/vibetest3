**今日作るのは「体験授業の問い合わせ管理」に絞ります。**

## 解く課題

- **困っていること**: 体験授業の問い合わせがLINE・電話・HPの3経路からバラバラに届き、返信漏れが月2〜3件発生している

- 🔮 **今その人はどうやっているか**: LINEの未読、携帯の着信履歴、HPフォームの転送メールを**それぞれ別々に開いて確認**し、覚えている範囲で折り返している。紙のメモか、教室の共有Excelに転記している可能性が高い。3つを串刺しにした一覧はどこにも無いと思われる。
  - → 確かめ方: 「問い合わせが来たとき、どこにメモしていますか？ ノートですか、Excelですか、それとも頭の中ですか？」

- 🔮 **かかっている時間 / 費用**: 問い合わせは**月20〜30件**。1件あたり、3経路の確認＋転記＋返信文の作成で**10〜15分**。合わせて**月5〜7時間**。
  さらに返信漏れ2〜3件は、そのまま失注になっている可能性が高い。体験→入会が仮に5割なら、**月1〜1.5人の入会機会**を落としている計算になる。
  - → 確かめ方: 「体験の問い合わせって、だいたい月に何件くらい来ますか？ 1件返すのに何分くらいかかっていますか？」

- **なぜ今まで誰も解決していないのか**:
  - [x] **データが散っている** ← 🔮 これが主因と思われる
  - [ ] 市場が小さい　[ ] 量が多すぎる　[ ] 判断が非定型　[ ] n=1すぎる

  🔮 LINE・電話・HPフォームは**それぞれ持ち主が違うサービス**で、1本にまとめるAPIが存在しない。だから大手の塾管理システムも「入会後の生徒管理」から作られていて、**入会前のバラバラな問い合わせ**は各教室の手作業のまま残っていると思われる。
  - → 確かめ方: 「今お使いの塾システムに、入会前の問い合わせを入れる欄はありますか？」

- **このサイトで最初に成立させたいこと（1つだけ）**:

## 出口 ── 作る前に確認する3つ

### ① 誰が払うか

- 🔮 **払う人**: 使う人は田中教室長。ただし**払う人は教室のオーナー（FCオーナー）**の可能性が高い。
  月額3,000〜5,000円程度であれば、**教室長の裁量経費（消耗品・広告費枠）で通る**線が現実的と思われる。
  - → 確かめ方: 「教室で使うツールを月3,000円くらいで入れるとき、田中さんの判断で決められますか？ それともオーナーの承認が要りますか？」

- 🔮 **その相手は、この種のものに金を出す商習慣があるか**: **ある**と思われる。学習塾は生徒管理・保護者連絡のシステム（Comiru、Cyber Home 等）に月額を払う文化がすでにある。ゼロから習慣を作る必要はない。
  - → 確かめ方: 「今、教室で月額を払っているツールって何がありますか？」

### ② どう届くか

- 🔮 **その市場が「実際に使っている」経路**: **下の経路（紹介・口コミ・業界内の直接接触）**。
  具体的には、**同じFC内の教室長どうしの横のつながり**と**エリア長・ブロック会議**。
  塾業界は「隣の教室が使って成果が出た」で広がりやすく、検索広告は大手SaaSベンダーが押さえていて勝てないと思われる。

| | 経路 | 今回の判断 |
|---|---|---|
| 上 | 検索・広告・コールドDM・SNS | 🔮 使わない。大手SaaSと同じ土俵になり不利 |
| 下 | **同一FCの教室長どうし／エリア長会議／既存の知り合い** | 🔮 **ここが取り分。田中さん経由で隣の教室に渡る形を狙う** |

  - → 確かめ方: 「他の教室の先生と、便利だったツールの話をすることってありますか？ それはどこで話しますか？」

### ③ 受け取れるか（決済・審査・規制）

- **確認したか**: はい
- **確認した内容**: 学習塾向けの**業務管理ツール**は、要確認業種（投資・金融／医療・健康／サプリ・美容の効能／法律相談／暗号資産／ギャンブル／アダルト／情報商材）の**いずれにも該当しない**。決済・審査の障害は無い。

  ただし1点だけ制約があります。扱うのが**生徒・保護者の氏名と連絡先という個人情報**であるため、今回は**データを外部サーバーに送らず、教室長の端末内（localStorage）にだけ保存**します。この設計であれば、今の段階で個人情報の預かり責任は発生しません。

### 競合には必ず「DIY」を入れる

- 🔮 **既存の競合**:
  - 塾管理システム（Comiru、スクパス 等）── **入会後の生徒管理が主戦場**で、入会前の問い合わせは手薄
  - Googleスプレッドシート ── 無料で作れるが、**誰も作って渡してくれない**
  - LINE公式アカウントのタグ・メモ機能 ── LINE経由の問い合わせしか入らない

- 🔮 **DIY競合**（顧客が自分でAIに作らせる）: 田中教室長自身が ChatGPT にスプレッドシート＋GASを作らせる。
  **今の田中さんは、たぶんこれをやらない**と思われる。理由は作れないからではなく、**平日の夜は授業と保護者面談で埋まっていて、作る時間そのものが無い**ため。ただしこれは半年で変わる可能性がある。
  - → 確かめ方: 「Excelやスプレッドシートで自分用の管理表を作ったこと、ありますか？」

- 🔮 **選ばれる理由**: **時間**（4つのうち「時間」で勝負する）
  「機能が多いから」ではなく、**朝の3分で、今日折り返す相手が確定する**。それ以上のことをしない。
  入力項目を5つに絞り、体験授業の受付フローの言葉（未返信／返信済み／体験予定／入会／見送り）だけで組むので、**説明なしでその場で使い始められる**状態を狙います。
  - → 確かめ方: 「朝、教室に来て最初にやることは何ですか？ そのとき何を見ていますか？」
