## 3行の評価（1つだけ）

2行目に数字（1日10人・15分）が入っているのは強いです。**いちばん弱いのは1行目です。**
「斉藤内科の院長」までは分かりますが、**あなたとの関係が「患者の家族」**で、業務の話ができる関係かが分かりません。
さらに、**実際に電話をかけているのが院長本人なのか、受付スタッフ・看護師なのか**が決まらないと、画面をどちらに向けて作るかが決まりません。
今回は「**院長が使い、受付も同じ画面を見る**」と仮に置いて進めます（🔮 が付きます）。

## 今回の絞り込み

**今日作るのは「検査結果の“連絡待ち”管理」に絞ります。**
検査会社・電子カルテとの自動連携、患者さん側への自動通知（SMS・メール）、予約の受付は、
**外部システム連携とお客さん側からの入力**にあたるため今回は作りません（第2〜3回で扱います）。
今回は、**院内の人が「結果が返ってきた」を1件登録し、電話したら状態を切り替える**部分だけを作ります。

> 絞った理由: 3行目の「まだ電話していない人が、返ってきた順に一覧で分かる」は、**検査会社とつなぎ込まなくても、手元に1本の台帳があれば成立する**ためです。

## 解く課題

- **困っていること**: 外部検査会社の結果は3〜5日後に返ってくる。返ってきたら患者に電話するが、**誰にまだ電話していないかが紙のメモにしか無い**。1日10人前後、探すのに15分。かけ忘れは翌週の外来で気づく

- 🔮 **今その人はどうやっているか**: 検査会社から届いた**結果帳票（PDF・FAX・専用端末の画面）を1枚ずつ見て**、電話が必要な人をその場で紙にメモしている。電話したら紙に線を引く。翌日は**前日の紙と今日の帳票の両方**を見比べることになり、線の引き忘れがそのままかけ忘れになっていると思われる。電子カルテには結果は入るが、「**電話したかどうか**」を入れる欄が無いか、あってもカルテを1人ずつ開かないと見えないと思われる。
  - → 確かめ方: 「結果が返ってきたとき、**電話する人のリストはどこに作っていますか**？ 紙ですか、カルテの中ですか？」

- 🔮 **かかっている時間 / 費用**: **1日15分 × 月22日 ＝ 月5.5時間**が「探すだけ」に消えている。
  さらにかけ忘れが**月2〜3件**発生していると思われる（1日10人 × 22日 ＝ 月220件のうち約1%）。
  かけ忘れ1件あたり、翌週の外来での説明のやり直し・受付での謝罪・カルテの追記で**30分前後**が追加で発生する。
  - → 確かめ方: 「かけ忘れって、月に何件くらいありますか？ 気づいたあと、何をやり直すことになりますか？」

- **なぜ今まで誰も解決していないのか**:
  - [x] **データが散っている** ← 🔮 これが主因と思われる
  - [ ] 市場が小さい　[ ] 量が多すぎる　[ ] 判断が非定型　[ ] n=1すぎる

  🔮 **「検査結果」と「連絡したかどうか」の持ち主が違う**ためだと思われる。検査結果は**外部の検査会社**のもの、カルテは**電子カルテベンダー**のもの、そして「電話したか」は**院長の頭と紙メモ**の中にしか無い。
  電子カルテは「診察の記録を残す」ために作られていて、**診察と診察のあいだの“宿題”を並べる**ようには作られていないと思われる。だから各医院の手作業のまま残っている。
  - → 確かめ方: 「今のカルテに、**“この人にまだ電話していない”を入れておく欄**はありますか？」

- **このサイトで最初に成立させたいこと（1つだけ）**:
  **診療の合間に開くと、「結果は返ってきたが、まだ電話していない人」だけが、返ってきた順に上から並んでいる状態をつくる。**

## 出口 ── 作る前に確認する3つ

### ① 誰が払うか

- 🔮 **払う人**: **院長本人**の可能性が高い。個人開業の医院は、使う人と払う人と決裁者が**同じ1人**であることが多く、これは学習塾のFCなどより有利な構造だと思われる。月額3,000〜10,000円なら、**その場で決められる**線が現実的。
  ただし「使う人」は院長ではなく**受付スタッフ**の可能性がある。その場合でも**払うのは院長**のままだと思われる。
  - → 確かめ方: 「**院内で使うものを月数千円で入れるとき、先生の判断で決められますか？**」

- 🔮 **その相手は、この種のものに金を出す商習慣があるか**: **ある**と思われる。医院はすでに**電子カルテ・レセコン・予約システム**に月額を払っている。ゼロから習慣を作る必要は無い。
  むしろ逆で、**「またシステムが増えるのか」**という抵抗のほうが本当の壁になると思われる。
  - → 確かめ方: 「今、医院で月額を払っているシステムは何がありますか？ それぞれ**何年くらい**使っていますか？」

### ② どう届くか

- 🔮 **その市場が「実際に使っている」経路**: **下の経路（紹介・口コミ・業界内の直接接触）**。
  具体的には、**地区医師会の集まり／地域の症例検討会・勉強会／検査会社やメーカーの営業担当が置いていく話題／同じ電子カルテを使っている医院どうし**。
  医師は**同業の実名の推薦を非常に重く見る**一方、広告経由のツールは警戒されやすいと思われる。上の経路（検索・広告）は電子カルテベンダーが押さえていて勝てない。

| | 経路 | 今回の判断 |
|---|---|---|
| 上 | 検索・広告・コールドDM・SNS | 🔮 使わない。大手ベンダーと同じ土俵になり不利 |
| 下 | **地区医師会／地域の勉強会／検査会社の営業担当／同じカルテの利用者どうし** | 🔮 **ここが取り分。斉藤先生から近隣の先生へ渡る形を狙う** |

  - → 確かめ方: 「**便利だったツールの話を、他の先生とすることはありますか？ それは医師会ですか、勉強会ですか、それとも検査会社の営業さんからですか？**」

### ③ 受け取れるか（決済・審査・規制）

- **確認したか**: はい。ただし**この題材は、これまでで一番グレーに近いところにあります。**

- **確認した内容**:
  - 🔮 **決済・審査**: 売るのは「**医療機関向けの院内業務管理ツール**」であり、**診断をしない・治療をしない・健康の効能をうたわない**。この形なら要確認業種（投資・金融／医療・健康／サプリ・美容の効能／法律相談／暗号資産／ギャンブル／アダルト／情報商材）の**「医療・健康」には該当しない可能性が高い**と思われる。
    ただし紹介文に「**検査結果**」「**患者**」という語が並ぶため、**審査で説明を求められる可能性は残る**。
    - → 確かめ方: 決済を入れる段階になったら、決済代行の審査窓口に「**医療機関向けの社内業務管理SaaS。診断・治療・健康効能は扱わない**」と書いて事前確認する。

  - **個人情報（ここは仮説ではなく、確定した制約です）**: 扱うのが**患者の氏名と検査に関する情報**で、これは個人情報保護法の**要配慮個人情報**にあたります。したがって次の3つを設計の前提にします。
    1. **データを外部サーバーに送らない。** 保存先は院内の端末の中（localStorage）だけ
    2. **検査結果の数値そのものを持たない。** 持つのは「連絡が必要かどうか」と「電話したかどうか」だけ
    3. **氏名はフルネームを必須にしない。** カルテ番号＋姓だけで運用できる形にする

  > この3つを守るかぎり、このツールは「**紙のメモの置き換え**」の範囲にとどまります。
  > 逆に、クラウドに患者データを預ける形にした瞬間、**医療情報システムの安全管理ガイドライン**が求める世界に入り、個人が数週間で出せるものではなくなります。今回はそこに踏み込みません。

### 競合には必ず「DIY」を入れる

- 🔮 **既存の競合**:
  - **電子カルテ（エムスリーデジカル、CLINICS、Medicom 等）** ── **診察の記録が主戦場**。結果は入るが「まだ電話していない人の一覧」は出しにくいと思われる
  - **検査会社が提供する結果閲覧システム** ── 結果は見られるが、**院内の“電話したか”は持たない**
  - **紙のメモ・付箋・ホワイトボード** ── **これが本当の現役チャンピオン**。無料・訓練不要・落ちない。ここに勝てないと何も始まらない
  - **Googleスプレッドシート** ── 作れるが、**患者情報を外部クラウドに置くことになる**ため、医院では使いにくい

- 🔮 **DIY競合**（顧客が自分でAIに作らせる）: 斉藤院長自身が ChatGPT にスプレッドシートを作らせる。
  **今の院長は、たぶんこれをやらない**と思われる。作れないからではなく、**診療・往診・レセプト・学会で平日も土曜も埋まっていて、作る時間そのものが無い**ため。
  ただし**医師はITに強い人が一定数いる**ので、学習塾の例より DIY の確率は高いと見ておくべきだと思われる。
  - → 確かめ方: 「**Excelで先生ご自身が作った表**って、院内にありますか？」

- 🔮 **選ばれる理由**: **時間**（4つのうち「時間」で勝負する）
  「機能が多いから」ではなく、**診療の合間の1分で、今日かけ直す相手が確定する**。それ以上のことをしない。
  項目は5つだけ、状態は院内の言葉（連絡待ち／連絡済み／不在・かけ直し／来院時に説明）だけで組むので、**説明なしでその場で使い始められる**状態を狙います。
  - → 確かめ方: 「**結果が返ってきた日、どのタイミングで電話していますか？** 昼休みですか、診療後ですか？」

  > **「責任」では書きません。** かけ忘れ防止は医療安全に直結しますが、**その結果に責任を取れるのは医院側**であり、私たちが取れません。「これを使えばかけ忘れが無くなる」とは書かない、が今回の線です。

## やらないこと（3つ）

1. **検査会社・電子カルテとの自動連携をしない。** 結果が返ってきたら、院内の人が手で1件登録する。
2. **患者さん側の画面と自動通知を作らない。** 結果の閲覧・SMS・自動架電・予約は今回は無し。
3. **検査結果の数値・所見を持たない。** 持つのは「連絡が必要か」と「電話したか」だけ。**カルテの代わりにはしない。**

## 🔮 次回までに確かめること

1. **② どう届くか — 先生どうしで、院内のツールの話が実際に回るのか** → 誰に聞くか：斉藤内科の院長 → 質問：「**便利だった院内のツールの話を、他の先生とすることはありますか？ それは医師会の集まりですか、勉強会ですか、それとも検査会社の営業さんからですか？**」
2. **使う人が誰か — 院長本人か、受付スタッフか** → 誰に聞くか：同上 → 質問：「**検査結果の電話は、先生ご自身がかけていますか？ それとも受付の方が“結果が出ています”と一次連絡していますか？**」
3. **紙のメモに勝てるか — 今どこにリストを作っているか** → 誰に聞くか：同上 → 質問：「**結果が返ってきたとき、電話する人のリストはどこに作っていますか？ そのやり方で一番困るのはどこですか？**」

このうち ② どう届くか だけは、量では取り返せません。最優先で確かめてください。
